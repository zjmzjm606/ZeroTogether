# ZeroTogether

[English](README.md) | 简体中文

**ZeroTogether** 是 yhsharaf 的[幻影契约(Phantom Pact)](https://github.com/yhsharaf/PhantomPact)的一个非官方增强分支。幻影契约是《影之刃零》的线上联机模组,
它原有的功能这里全部保留,另外加了下面这些新功能和修复。ZeroTogether 不是 yhsharaf 或 S-GAME 制作或认可的,幻影契约本身的功劳归原作者。

> 这些改动是新做的,还在实际游玩中测试。ZeroTogether 新增部分的问题请提到[本仓库的 Issues](https://github.com/zjmzjm606/ZeroTogether/issues),不要提给幻影契约。

## ZeroTogether 加了什么

**新功能**

- **头顶名字和血条:** 每个队友头上显示名字(用他的玩家颜色,倒地时变红)和一条血条。60 米内显示,45 米开始变淡。
- **左侧队伍列表:** 屏幕左边先列你自己,再列每个队友:名字、血量和血气(游戏里血条下面那条 ShaChi)的数值,各配一条进度条。队友在别的地图、过场中或没有响应时,那一行变灰。
- **自定义名字:** 在 `PhantomPact.ini` 里设置 `PlayerName`,最多 16 个字,中文也行。改完几秒内队友就能看到,不用重启。
- **更好看的血条:** 黑色细边框、看得见的空槽、挨打后停一下再滑落的掉血残影,以及顶部一道淡淡的高光。
- **Boss 战中倒地:** 等待战斗结束时,Boss 血条一直显示,声音跟着看队友的镜头走。队友打出最后一个 Boss 的最后一击时,会先把你在队友身边原地拉起来,这样 Boss 的胜利流程和结局过场你也能看到(`BossWinRevive`)。
- **隐藏联机界面:** 按 F9 隐藏头顶名字和左侧队伍列表,再按一次显示(`HideUIKey`)。队伍列表的位置往上移了,也可以自己调(`PartyBarsY`)。
- **选择 F3 传送到谁那里:** 三人及以上的队伍里,按 Shift+F3 在"最近的队友"和每个玩家之间切换,选中的人在队伍列表里前面有个 »。选中的人倒地或离开时,F3 会改为传送到最近的队友。
- **重置键:** 卡住时按 F10(`ResetKey`):关掉所有物品卡,把操作还给你,停掉你自己的动作,附近如果有队友开了、但在你这边没动的门,就让你直接穿过去。

**修复**

- **客机第一次进房间后不能动、什么键都没用。** 按 F5 打开面板时,操作会切到"只操作菜单"模式。客机第一次加入时游戏会读图把你送进主机的世界,读图会换掉玩家控制器,面板关闭时就没把操作切回来。现在会用当前的控制器切回;还在读图的话,等控制器出现后马上切回。联机、PvP、本地分屏三个面板都修了。
- **另一边看不到完整的处决动画。** 处决进行到一半时传来的死亡会直接打断敌人的动画,客机的致命一击也没有带上动画给主机播放。现在死亡会等处决播完(最多 2.6 秒)。
- **联机打 Boss 时出现两条血条。** 游戏自己的血条和 mod 替队友那边战斗挂的血条可能同时留着。现在每个 Boss 只留一条,留下的那条跟着共享战斗的血量走。
- **主机一过来,怪的血就回满了。** 主机离得远(大约 120 米以上)时,不会同步客机附近的怪,客机打的伤害主机那边收不到。主机一走近,主机那只满血的怪就接管了。现在两边的怪对上的那一刻,客机打掉的血会同步给主机。
- **捡东西时被物品卡卡住。** 游戏有时会留下一张没有按钮的物品卡,没有任何键能关掉。现在这种卡 3 秒后会自动关掉(东西已经进背包了)。按 F10 能立刻关掉任何物品卡。
- **有些门只有第一个人能开。** 队友开的门在你的世界里是跳过开门动画直接打开的,而有些门只有在动画里才会动:门一直关着,交互键也没了。现在如果 2 秒后门的任何部分都没动,就让你直接穿过去。

## 安装

1. 按 [INSTALL.zh-CN.md](INSTALL.zh-CN.md) 的说明,装好 **UE4SS for Phantom Blade Zero**(Vercadi,Nexus Mods)1.0.3 或更新版,以及**幻影契约 1.7.4**。ZeroTogether 需要幻影契约发布包里编译好的 `main.dll`,这个源码仓库里没有。
2. 下载本仓库(**Code → Download ZIP**),把 `mod/PBZCoop/Scripts` 和 `mod/PBZCoop/art` 复制到 `PBZ\platform\steam\ue4ss\Mods\PBZCoop\`,替换原有文件。你的 `PhantomPact.ini` 不会被动到。
3. 每个玩家都要装 ZeroTogether:名字、血气和客机那边的修复都需要两台电脑都装。没装的玩家也能正常联机,只是显示成"主机"或"玩家 2",也只有血量。

## 新增设置(`PhantomPact.ini`)

第一次启动时,ZeroTogether 会把这几行加到文件末尾。每台电脑各自设置。

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `PlayerName` | 空 | 你在别人屏幕上显示的名字。留空则显示"主机"或"玩家 2"等。 |
| `Nameplates` | `On` | 在其他玩家头上显示名字和血条。 |
| `PartyBars` | `On` | 屏幕左侧的队伍列表。 |
| `BossWinRevive` | `On` | 最后一个 Boss 倒下时把倒地的玩家拉起来看结局。`Off`:像以前一样回钟那里复活。 |
| `PartyBarsY` | `22` | 队伍列表从屏幕顶部往下多少开始,按屏幕高度的百分比算。 |
| `HideUIKey` | `F9` | 隐藏/显示头顶名字和队伍列表。 |
| `ResetKey` | `F10` | 上面说的重置键。 |

# 幻影契约(Phantom Pact):《影之刃零》线上联机模组

[English](README.md) | 简体中文

幻影契约(Phantom Pact)为《影之刃零》加入线上双人联机。两名玩家各自运行自己的游戏、保留自己的存档,模组把两个世界连接起来:你们能看到彼此,一起对付同样的敌人和首领,共享战利品和尘,并在钟旁会合。游戏世界以房主为准,搭档加入其中。

**下载:**[最新版本](https://github.com/yhsharaf/PhantomPact/releases/latest) · **安装和游玩:**[INSTALL.zh-CN.md](INSTALL.zh-CN.md) · **发现问题?**[提交 Issue](https://github.com/yhsharaf/PhantomPact/issues/new/choose)

## 功能

- 实时看到搭档的魂,包括移动、攻击、闪避和受击反应
- 两个世界的敌人同步,血量、架势和处决都是共享的
- 搭档的攻击在房主的世界同样有效,可以一起打同一个敌人
- 搭档打中敌人时,你的画面上也有游戏原有的击中音效和血迹(1.7.1 新增)
- 共享首领战:两名玩家都能看到首领血条和场地雾墙
- 共享战利品和尘:任何一方拾取或获得,双方都有
- 钟旁会合:你在钟旁休息时,已死亡或正在观战的队友会来到你身边。每位玩家在自己休息时恢复,与原作相同;正在与首领战斗的队友会重新开始这场战斗:恢复状态,首领也回满生命值
- 《艾尔登法环》式的联机难度:一起游玩时,敌人和首领的血量、架势更高
- PvP 比赛(F6,1.7.0 新增):决斗(三局两胜)和死斗,一对一或最多六人分两队,在游戏自己的四个首领场地或房主所在的地方进行。对所有人都公平:同样的身体、自选的 30 级武器、同一个葫芦喝三口、水墨笔触的倒数、对手显示在游戏自己的首领血条上、可选的限时,还能用首领的招式终结败者。比赛中的一切都不会存档,结束后全部还原(详见 [docs/PVP.md](docs/PVP.md),英文)
- PvPvE(更多 > PvPvE):在开放世界和搭档交手,敌人照样在场:使用游戏自带的格挡、弹反和闪避;弹反会让攻击者硬直;败者死亡
- 游戏水墨风格的搭档罗盘、搭档提示,倒下后可观战搭档
- 可选的 `Secret` 密码,为每个数据包签名;支持 UU 加速器、Tailscale、Hamachi、Radmin、ZeroTier 和 Steam(测试版)
- English、中文和 العربية(阿拉伯语,1.7.2 新增):F5 面板、PvP 页面和模组的提示都可以切换语言
- 本地双人(分屏,测试中):同一台电脑两名玩家,各用一个手柄,或键鼠加手柄,也可以各用一台显示器(F4 面板,或 `Monitors = 2`,1.7.2 新增)。按 F5,在“更多”里把“模式”设为“本地分屏”,然后重启游戏(或设置 `Role = Local`)。玩家 2 可以自己攀爬、开宝箱、敲钟、喝葫芦、战斗;敌人会发现并攻击单独行动的玩家 2;菜单和游戏界面双方共用;Boss 血条也显示在玩家 2 的半屏。游戏中按 F4 打开面板,设置分屏方式和手柄。详见 docs/LOCAL_COOP.md(英文)。
- 不需要安装 Python:联机程序运行在游戏内部

## 快速开始

1. 双方都安装 [UE4SS for Phantom Blade Zero](https://www.nexusmods.com/phantombladezero/mods/5),以及一款虚拟局域网工具(UU 加速器联机功能、Tailscale 等)。
2. 把发布的压缩包解压到游戏的 `PBZ` 文件夹。
3. 编辑 `platform\steam\ue4ss\Mods\PBZCoop\PhantomPact.ini`:房主设置 `Role = Host`,客人设置 `Role = Guest`,并把 `HostAddress` 设为房主的虚拟局域网 IP。
4. 启动游戏并读取存档,房主先进。联机会自动开始。也可以在游戏中按 F5 打开联机面板,直接开房或加入,不用改文件。

目前是早期版本,支持两名玩家。4 人模式为测试版,6 人模式为实验版:房主在 F5 面板“更多”的“人数”里选择后,最多三名或五名队友可以加入。五人或六人时,每个敌人和首领都会有一个红眼青色的幽灵双生,详见 [INSTALL.zh-CN.md](INSTALL.zh-CN.md#4-人模式测试版和-6-人模式实验版)。

双方必须使用相同版本:这个版本换了新的连接方式,1.7.3 及更早的版本无法与它连接。连不上或感觉卡顿时,请看 [INSTALL.zh-CN.md](INSTALL.zh-CN.md#连接问题) 的“连接问题”一节。

## 基本原则

- **不绕过 DRM。** 幻影契约不碰 Denuvo,也不修改游戏的可执行文件。一切都通过 UE4SS 加载,运行在正版游戏之内。
- 每位玩家都需要拥有自己的游戏。
- 本项目不包含任何游戏文件或素材。
